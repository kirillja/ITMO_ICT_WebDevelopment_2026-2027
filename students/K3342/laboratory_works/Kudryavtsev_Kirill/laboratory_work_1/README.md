## Запуск

Нужен Python 3.10 или новее. Для приложений достаточно стандартной библиотеки.
Все команды выполняются из папки `laboratory_work_1`.
Сначала запускайте сервер, затем клиент в другом терминале.

| Задание | Сервер | Клиент |
| --- | --- | --- |
| 1 UDP | `python3 -m task1.server` | `python3 -m task1.client` |
| 2 TCP | `python3 -m task2.server` | `python3 -m task2.client` |
| 3 HTML | `python3 -m task3.server` | Открыть http://127.0.0.1:9003/ |
| 4 Чат | `python3 -m task4.server` | `python3 -m task4.client` в нескольких терминалах |
| 5 Журнал | `python3 -m task5.server` | Открыть http://127.0.0.1:9005/ |

Адрес по умолчанию — `127.0.0.1`, порты — 9001–9005.
Серверы и клиенты принимают `--host` и `--port`.
В чате имя вводится с клавиатуры, команда `/quit` завершает участие.
Серверы останавливаются по Ctrl+C.
Журнал создаёт `task5/grades.json`; можно выбрать другое хранилище через `--data путь`.

## Проверки

```sh
python3 -m unittest discover -s tests -v
```

Проверки запускают реальные процессы серверов на свободных локальных портах,
проверяют обмен по сети и удаляют временный журнал после завершения.

## Отчёт MkDocs

```sh
python3 -m venv .venv
source .venv/bin/activate
python -m pip install -r requirements-docs.txt
mkdocs build --strict
mkdocs serve
```

Исходный отчёт находится в `docs/lr1/report.md`. Полный код клиента и сервера
приведён в `docs/lr1/source.md`. Для публикации из этой папки в форке:

```sh
mkdocs gh-deploy --remote-name origin
```

В настройках Pages нужно выбрать ветку `gh-pages` и папку `/ (root)`.
Не добавляйте `site/`, `.venv/`, `__pycache__/` или созданный журнал в коммит.
