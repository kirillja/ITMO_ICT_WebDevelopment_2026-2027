# Подготовка к защите

## UDP и TCP

UDP отправляет отдельные датаграммы и сохраняет их границы. Он не гарантирует
доставку и порядок. TCP устанавливает соединение и передаёт упорядоченный
поток байт. Границы вызовов `sendall()` не совпадают с границами `recv()`:
получатель должен сам выделять сообщения по `\n` или указанной длине.

`AF_INET` означает IPv4. `SOCK_DGRAM` выбирает UDP, `SOCK_STREAM` — TCP.
`bind()` связывает сокет с локальным адресом. `listen()` переводит TCP-сокет
в режим приёма подключений. `accept()` возвращает новый сокет отдельного клиента.
`sendall()` продолжает отправку, пока все байты не переданы или не произошла ошибка.

## Почему HTTP работает через обычный сокет

HTTP — формат сообщений поверх TCP. После первой строки идут заголовки,
затем пустая строка и тело. Для чтения POST нельзя считать, что всё тело уже
получено вместе с заголовками: его нужно дочитать по Content-Length.
В UTF-8 кириллица занимает несколько байт; длину считают после кодирования.

## Почему чату нужны блокировки

Несколько потоков одновременно добавляют и удаляют клиентов. Общая блокировка
защищает словарь и проверку уникальности имён. Отдельная блокировка отправки
сериализует сообщения одному получателю. Сетевую рассылку выполняют после
освобождения общей блокировки, чтобы не держать её на время всех отправок.

## Как журнал группирует оценки

Ключ словаря — название дисциплины, значение — список оценок.
`setdefault(subject, []).append(grade)` добавляет оценку в существующую
запись или создаёт новый предмет. После POST сервер возвращает 303;
браузер выполняет GET, поэтому обновление страницы не повторяет POST.

## Что показать преподавателю

1. Запустить UDP-клиент и показать обе приветственные строки.
2. Ввести катеты 3 и 4 и получить 5; показать обработку неверного ввода.
3. Открыть HTML-сервер и объяснить Content-Length.
4. Запустить три одинаковых клиента чата с разными именами, передать сообщения и выйти.
5. Добавить две оценки одного предмета, показать одну строку и сохранение после перезапуска.
6. Запустить `python3 -m unittest discover -s tests -v` и открыть отчёт MkDocs.
